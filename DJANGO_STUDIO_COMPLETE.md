## 🚀 Quick Start

### Installation

```bash
cd Django-Studio
python -m venv .venv
.\.venv\Scripts\Activate.ps1    # Windows
source .venv/bin/activate        # macOS/Linux
pip install -r requirements.txt
```

### Run Application

```bash
python src/main.py
```
