---

DESIGN PRINCIPLES
=================

1. DJANGO BRANDING
   - All primary accents use Django's official colors
   - Creates strong visual connection to Django framework
   - Professional, recognizable appearance

2. HIERARCHY
   - Primary text (#E8EEF5) for main content
   - Secondary text (#A8B5C4) for subtext
   - Muted text (#7A8895) for comments/disabled

3. CONTRAST
   - High contrast between text and backgrounds
   - Ensures readability and accessibility
   - WCAG AA compliant for most combinations

4. CONSISTENCY
   - Same colors used across all components
   - Hover/active states follow patterns
   - Status colors are consistent globally

5. PROFESSIONAL
   - Dark theme reduces eye strain
   - Modern, clean appearance
   - Enterprise-grade look and feel

---

IMPLEMENTATION
==============

All colors are defined in:
  src/theme/django_theme.py

Access colors in code:
  from theme.django_theme import DjangoTheme
  
  DjangoTheme.DJANGO_GREEN        # #092E20
  DjangoTheme.ACCENT_PRIMARY      # #44B78B
  DjangoTheme.PRIMARY_BG          # #0F1419
  etc.

Generate stylesheets:
  stylesheet = DjangoTheme.get_stylesheet()
  toolbar_css = DjangoTheme.get_toolbar_stylesheet()
  editor_css = DjangoTheme.get_editor_stylesheet()

---

CUSTOMIZATION
=============

To modify colors, edit django_theme.py:

1. Change color constants (DJANGO_GREEN, etc.)
2. Stylesheets will automatically use new colors
3. All components will update instantly

Colors are centralized for easy theming.
