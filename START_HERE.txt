QUICK START
===========

1. Install Dependencies:
   ```
   cd Django-Studio
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1        # Windows
   source .venv/bin/activate            # macOS/Linux
   pip install -r requirements.txt
   ```

2. Run Application:
   ```
   python src/main.py
   ```

3. Create or Open Django Project:
   - Welcome window guides you
   - Create new or open existing
   - Start coding immediately

THEME CUSTOMIZATION
===================

All theme colors are defined in one file:
  src/theme/django_theme.py

To customize:
  1. Edit color constants in django_theme.py
  2. All components automatically update
  3. No need to modify individual files
